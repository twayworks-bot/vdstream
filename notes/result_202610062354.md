## 1. 개요 및 구현 목적

사용자의 요구사항에 따라 VDSTREAM 서비스를 독립적인 Docker 컨테이너로 빌드하고 운영 배포할 수 있도록 `Dockerfile`을 작성하였습니다.
본 구현에서는 다음 핵심 요구사항을 모두 충족합니다:
1. **FFmpeg/FFprobe 실행 환경 탑재**: Linux `python:3.11-slim` 기반 컨테이너에 시스템 패키지로 설치 및 `FFMPEG_PATH=/usr/bin/ffmpeg`, `FFPROBE_PATH=/usr/bin/ffprobe` 고정.
2. **지속성 볼륨(Persistent Volume) 경로 환경 설정**: SQLite DB 및 비디오 파일 영구 보존을 위한 `STORAGE_DIR=/app/storage`, `DOWNLOAD_DIR=/app/downloads`, `DB_URL=sqlite:////app/storage/vdstream.db` 환경변수 및 `VOLUME ["/app/storage", "/app/downloads"]` 선언.
3. **서비스 노출 포트**: `EXPOSE 5000` 설정.
4. **동적 Base URL Prefix 지원**: `ENV DEFAULT_PREFIX=/vdstream` 설정을 바탕으로 웹앱 및 API의 base URL이 동적으로 작동.
5. **컨테이너 헬스체크(HEALTHCHECK)**: 사용자 지정 파이썬 requests 기반 헬스체크 명령어 완벽 수용 및 `app/main.py`에 `GET /{base_prefix}/api/status` 및 `GET /api/status` 엔드포인트 제공.
6. **기동 CMD 및 진입점 규격**: `main:app`을 직접 참조할 수 있도록 루트 `main.py`를 제공하고 `CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "5000"]` 적용 (Gunicorn 설정 옵션 주석 병기).

## 3. 세부 사양 검증

### 3.1 Dockerfile 구성

```dockerfile
FROM python:3.11-slim

ENV PYTHONDONTWRITEBYTECODE=1 \
    PYTHONUNBUFFERED=1

RUN apt-get update && apt-get install -y --no-install-recommends \
    ffmpeg \
    curl \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app

ENV FFMPEG_PATH=/usr/bin/ffmpeg \
    FFPROBE_PATH=/usr/bin/ffprobe

ENV DEFAULT_PREFIX=/vdstream

ENV STORAGE_DIR=/app/storage \
    DOWNLOAD_DIR=/app/downloads \
    DB_URL=sqlite:////app/storage/vdstream.db

ENV HOST=0.0.0.0 \
    PORT=5000 \
    DEBUG=False \
    MAX_CONCURRENT_TRANSCODE=3 \
    MAX_CONCURRENT_STREAMS=5 \
    MAX_OUTPUT_VIDEO_SIZE_MB=100 \
    MAX_VIDEO_DURATION_SECONDS=600 \
    RETENTION_DAYS=365

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . /app
RUN mkdir -p /app/storage /app/downloads

EXPOSE 5000
VOLUME ["/app/storage", "/app/downloads"]

HEALTHCHECK --interval=30s --timeout=10s --retries=3 --start-period=5s \
    CMD python -c "import os, requests; prefix = os.getenv('DEFAULT_PREFIX', ''); requests.get(f'http://localhost:5000{prefix}/api/status')"

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "5000"]
```

## 4. 실행 및 배포 가이드 요약

```bash
# 1. 이미지 빌드
docker build -t vdstream:latest .

# 2. 볼륨 마운트 및 컨테이너 실행
docker run -d \
  --name vdstream-server \
  -p 5000:5000 \
  -e DEFAULT_PREFIX=/vdstream \
  -v $(pwd)/storage:/app/storage \
  -v $(pwd)/downloads:/app/downloads \
  vdstream:latest

# 3. 헬스체크 상태 확인
docker ps
```
