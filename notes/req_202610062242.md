## 2. 요구사항 항목별 분해 및 해석

| 항목 | 내용 | 세부 요건 및 제약 |
|---|---|---|
| **1. 비디오 업로드 및 트랜스코딩** | 비디오 업로드 시 최대 720p 해상도로 FFmpeg 기반 트랜스코딩 | 원본 영상 해상도가 720p 초과일 경우 720p로 다운스케일, 720p 이하일 경우 원본 해상도 유지/비율 보존. H.264/AAC 코덱 최적화 |
| **2. 용량 및 길이 제약** | 결과 영상 제약 검증 | 트랜스코딩된 영상 용량 최대 100MB 이하, 영상 길이 10분(600초) 이하 강제 |
| **3. 동시성 및 큐잉 제어** | 업로드/트랜스코딩 동시 작업 수 제어 | 최대 동시 작업 수 $N < 5$ (설정값 기본 3). 초과 시 FIFO 작업 대기열(Queue)에 수용 (최대 큐 크기 초과 시 429/에러 반환) |
| **4. 동시 스트리밍 제어** | 동시 시청 스트림 수 제어 | 최대 $M = 5$개 동시 스트리밍 지원. 활성 스트림 세션 트래킹 및 만료/하트비트 관리, 슬롯 초과 시 거부/대기 응답 |
| **5. 동영상 스트리밍 지원** | 다운로드 없이 즉시 재생 | HLS(m3u8/ts) 스트리밍 및 HTTP Range(Pseudo-streaming) 이중 지원 |
| **6. 영상 보관 및 만료 관리** | 저장 보관 주기 관리 | 기본 365일 (설정 기반 `RETENTION_DAYS`), 만료 영상 감지 및 자동 삭제 스케줄러/정리 기능 |
| **7. 관리 웹 대시보드** | 영상 목록 조회, 상태 확인, 실시간 재생, 관리 | 웹 UI 제공: 업로드 모달/폼, 상태 프로그레스, 스트리밍 비디오 플레이어, 비디오 메타데이터 및 삭제 기능 |
| **8. 외부 연동 REST API** | 다른 웹앱 연동 인터페이스 | 비디오 업로드, 작업 상태 폴링/조회, 스트리밍 URL 조회, 비디오 삭제/목록 조회 API |
