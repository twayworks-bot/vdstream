## 1. MVP (Minimum Viable Product) 정의

VDSTREAM의 핵심 가치는 **"안정적인 리소스 제어 하에 비디오를 업로드하여 720p로 자동 트랜스코딩하고, 대기 없이 즉시 스트리밍하며, 1년간 안전하게 보관 및 관리하는 것"**입니다.

### MVP 필수 포함 기능 (Must-Have Scope)
1. **비디오 업로드 & 메타데이터 보관**:
   - Web 대시보드 및 REST API를 통한 비디오 수신.
   - 메타데이터 및 상태(QUEUED, PROCESSING, COMPLETED, FAILED) DB 기록.
2. **FFmpeg 트랜스코딩 파이프라인**:
   - 최대 720p 해상도 다운스케일링 및 H.264/AAC MP4 & HLS(.m3u8/.ts) 동시 생성.
   - 영상 길이 10분(600초) 이하, 결과물 파일 크기 100MB 이하 제약 검증.
   - FFmpeg 바이너리 미설치 시 장애 없이 안전하게 사유를 반환하는 진단/대응 로직.
3. **동시성 큐 및 워커 풀 ($N < 5$, 기본 3)**:
   - 최대 3개 동시 트랜스코딩 세마포어.
   - 초과 작업 FIFO 대기 큐 및 큐 한도(20개) 초과 시 과부하 차단.
4. **동시 스트리밍 세션 슬롯 통제 ($M = 5$)**:
   - 최대 5명 동시 스트리밍 세션 관리.
   - 하트비트 타임아웃 및 반환 메커니즘.
   - HLS 재생 및 HTTP Range 206 Partial Content 스트리밍.
5. **보관 기간(365일) 및 만료 관리**:
   - 업로드일 기준 365일 보관 만료일시 계산.
   - 만료 영상 자동 감지 및 파일/DB 삭제 스케줄러.
6. **외부 연계 API (`vdstream-api.md`)**:
   - 업로드, 상태 폴링, 스트리밍 URL 획득, 비디오 목록/삭제 REST API.
7. **웹 관리 대시보드**:
   - 실시간 시스템 자원 모니터(대기열, 진행수, 스트리밍 세션).
   - 비디오 업로드 드래그 앤 드롭 및 진행률 표시.
   - Hls.js 기반 내장 비디오 플레이어.
   - 비디오 목록 조회 및 삭제 기능.

## 2. 단계별 개발 세부 일정 및 태스크 계획 (Implementation Phases)

### Phase 1: 기반 아키텍처 및 설정 구축 (Environment & Core Setup)
- [x] `.env` 환경 변수 심층 분석 및 누적 보강 (트랜스코딩 파라미터, 스트리밍 타임아웃, 디렉토리 경로 등).
- [ ] 패키지 구조 초기화 (`app/`, `app/models/`, `app/services/`, `app/api/`, `app/dashboard/`, `app/templates/`, `app/static/`).
- [ ] Pydantic Settings 기반 `app/config.py` 환경변수 모듈 작성.
- [ ] SQLAlchemy 기반 비디오 데이터 모델 `app/models/video.py` 및 DB 세션 `app/database.py` 구현.

### Phase 2: 코어 서비스 엔진 개발 (Core Engines)
- [ ] **FFmpeg 서비스 (`app/services/ffmpeg_service.py`)**:
  - FFprobe 기반 비디오 메타데이터(지속 시간, 해상도, 비트레이트) 추출.
  - 10분(600초) 초과 유효성 검사.
  - 동적 비트레이트 계산을 통한 100MB 이하 보장 720p 트랜스코딩.
  - HLS 번들(m3u8, 4초 단위 ts) 생성.
  - FFmpeg 바이너리 유효성 진단 및 안전 모드(Fallback) 지원.
- [ ] **동시성 및 큐 매니저 (`app/services/queue_manager.py`)**:
  - `asyncio.Queue` 기반 FIFO 대기열.
  - $N=3$ 세마포어 기반 트랜스코딩 워커 풀.
  - 작업 상태 실시간 트래킹 및 오류 복구.
- [ ] **스트리밍 세션 매니저 (`app/services/stream_manager.py`)**:
  - $M=5$ 동시 세션 슬롯 풀.
  - 세션 발급, 하트비트 갱신, 세션 해제, 30초 타임아웃 가비지 컬렉터.
- [ ] **보관 기간 수명주기 서비스 (`app/services/retention_service.py`)**:
  - 만료일자(365일) 검사 및 파일 디렉토리 영구 삭제.

### Phase 3: 외부 연동 REST API 개발 (`app/api/`)
- [ ] `POST /api/v1/videos/upload`: 비디오 파일 업로드 및 인큐.
- [ ] `GET /api/v1/videos/{video_id}/status`: 트랜스코딩 진행 상태 조회.
- [ ] `GET /api/v1/videos/{video_id}/stream`: 스트리밍 전용 URL 및 세션 정보 획득.
- [ ] `GET /api/v1/videos`: 비디오 목록 및 메타데이터 페이징 조회.
- [ ] `DELETE /api/v1/videos/{video_id}`: 비디오 수동 삭제.
- [ ] `GET /api/v1/streams/{video_id}/master.m3u8`, `/api/v1/streams/{video_id}/segment/{name}`: HLS 세그먼트 전송.
- [ ] `GET /api/v1/streams/{video_id}/mp4`: HTTP 206 Range 비디오 전송.
- [ ] `POST /api/v1/streams/{session_id}/heartbeat`: 스트리밍 세션 유지.
- [ ] `POST /api/v1/streams/{session_id}/release`: 스트리밍 세션 종료 및 슬롯 반환.
