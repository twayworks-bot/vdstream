## 1. 개요 및 요구사항 반영 목적

환경변수 `DEFAULT_PREFIX` (기본값: `vdstream`)에 따라 웹 서비스 진입점 및 API 엔드포인트의 최상위 Basepath를 동적으로 바인딩하고, 이에 수반되는 전체 URL 계층 구조를 체계적으로 정의 및 구축하였습니다.

- **기본 진입 URL**: `http://localhost:5000/{DEFAULT_PREFIX}/dashboard`
- **기본 API 엔드포인트**: `http://localhost:5000/{DEFAULT_PREFIX}/api/v1/*`
- **기본 API 문서 (Swagger)**: `http://localhost:5000/{DEFAULT_PREFIX}/docs`

---

## 2. 웹 서비스 Basepath 및 Subpath 구조 정의

```text
http://<HOST>:<PORT>/
├── /                                           --> 307 Redirect to /{DEFAULT_PREFIX}/dashboard
└── /{DEFAULT_PREFIX}                           --> 307 Redirect to /{DEFAULT_PREFIX}/dashboard
    ├── /dashboard                              --> 웹 관리 대시보드 SSR UI
    │   ├── GET  /dashboard                     --> 대시보드 메인 화면
    ├── /docs                                   --> Swagger 대화형 API 문서 (OpenAPI UI)
    ├── /openapi.json                           --> OpenAPI 3.0 사양 JSON 메타데이터
    ├── /static/                                --> CSS/JS 정적 에셋 서빙
    │   ├── /css/style.css
    │   └── /js/dashboard.js
    └── /api/v1/                                --> RESTful API v1 서브패스
        ├── /videos                             --> 비디오 관리 및 업로드
        │   ├── POST /upload                    --> 비디오 업로드 및 큐잉 (202 Accepted)
        │   ├── GET  /{video_id}/status         --> 트랜스코딩 진행 상태 조회
        │   ├── GET  /{video_id}/stream         --> 스트리밍 세션 및 재생 URL 발급
        │   ├── GET                             --> 비디오 목록 페이징 조회
        │   └── DELETE /{video_id}              --> 비디오 즉시 영구 삭제
        ├── /streams                            --> HLS / MP4 Range 스트리밍 서빙
        │   ├── GET  /{video_id}/master.m3u8    --> HLS 매니페스트 서빙
        │   ├── GET  /{video_id}/mp4            --> HTTP 206 Partial Content MP4 Range 스트림
        │   ├── GET  /{video_id}/{segment}      --> HLS TS 세그먼트 전송
        │   ├── POST /{session_id}/heartbeat    --> 시청 세션 15초 하트비트 갱신
        │   └── POST /{session_id}/release      --> 세션 즉시 반환 (슬롯 회수)
        └── /system                             --> 시스템 리소스 모니터링
            └── GET  /status                    --> N/M 동시성 슬롯 및 엔진 상태
```

## 3. 코드 변경 및 영향도 처리 내역

1. **설정 모듈 ([`app/config.py`](file:///C:/Dev/python/vdstream/app/config.py))**:
   - `base_prefix` 프로퍼티 추가: `.env`의 `DEFAULT_PREFIX` 값을 안전하게 정규화(앞뒤 슬래시 정리)하여 반환 (`vdstream` -> `"/vdstream"`, 빈 문자열인 경우 `""`).
2. **FastAPI 메인 애플리케이션 ([`app/main.py`](file:///C:/Dev/python/vdstream/app/main.py))**:
   - `docs_url`, `redoc_url`, `openapi_url`을 `{base_prefix}/docs` 등으로 등록.
   - 정적 자산 마운트: `app.mount(f"{base_prefix}/static", ...)`
   - 라우터 마운트: `app.include_router(api_v1_router, prefix=f"{base_prefix}/api/v1")` 및 `dashboard_router, prefix=f"{base_prefix}/dashboard"`.
   - 루트(`/`) 및 `/{DEFAULT_PREFIX}` 요청 시 `{base_prefix}/dashboard`로 리다이렉트 핸들러 등록.
3. **API 응답 URL 동적 결합 ([`app/api/v1/videos.py`](file:///C:/Dev/python/vdstream/app/api/v1/videos.py))**:
   - `status_url`, `stream_info_url`, `hls_master_url`, `mp4_range_url` 생성 시 `settings.base_prefix`를 자동으로 접두하여 외부 앱이 올바른 타겟 URL을 수신하도록 보장.
4. **프론트엔드 대시보드 및 스크립트 ([`app/templates/base.html`](file:///C:/Dev/python/vdstream/app/templates/base.html), [`app/static/js/dashboard.js`](file:///C:/Dev/python/vdstream/app/static/js/dashboard.js))**:
   - `<meta name="base-prefix" content="{{ base_prefix }}">` 태그 주입.
   - JavaScript에서 `BASE_PREFIX` 상수를 통해 모든 API 호출(비디오 업로드, 상태 폴링, 스트리밍 시작/하트비트/종료, 삭제) 경로를 동적으로 구성.
5. **엔트리포인트 및 문서 동기화**:
   - [`run.py`](file:///C:/Dev/python/vdstream/run.py), [`README.md`](file:///C:/Dev/python/vdstream/README.md), [`vdstream-api.md`](file:///C:/Dev/python/vdstream/vdstream-api.md), [`notes/SPECIFICATION.md`](file:///C:/Dev/python/vdstream/notes/SPECIFICATION.md), [`notes/requirement.md`](file:///C:/Dev/python/vdstream/notes/requirement.md) 전체 동기화 완료.
