```text

웹앱의  prefix 값는 DEFAULT_PREFIX를 참조 하여  기본 base URL로 작동합니다.

HEALTHCHECK --interval=30s --timeout=10s --retries=3 --start-period=5s \
    CMD python -c "import os, requests; prefix = os.getenv('DEFAULT_PREFIX', ''); requests.get(f'http://localhost:5000{prefix}/api/status')"


시작 CMD 는 다음 2개 중 하나를 참조하여 생성합니다.
```
1) # Gunicorn 운영서버로 기동 (요청한 사양에 맞춘 최적화 워커 및 디버깅 로그 옵션)
CMD ["gunicorn", "--bind", "0.0.0.0:5000", "--workers", "2", "--log-level", "debug", "--access-logfile", "-", "--error-logfile", "-", "--capture-output", "main:app"]

2) # Run the FastAPI server using Uvicorn on port 5000
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "5000"]

## 2. 요구사항 분석 및 세부 기술 사양

| 항목 | 상세 분석 및 구현 방향 |
|---|---|
| **Base Image & FFmpeg** | `python:3.11-slim` 기반에 Debian 패키지 관리자를 통해 공식 `ffmpeg` 패키지 설치 (`/usr/bin/ffmpeg`, `/usr/bin/ffprobe`). 환경변수 `FFMPEG_PATH=/usr/bin/ffmpeg`, `FFPROBE_PATH=/usr/bin/ffprobe` 고정. |
| **Persistent Volume** | Database 및 미디어(업로드, 트랜스코딩, HLS) 영구 보존을 위한 스토리지 경로 환경변수 구성 (`STORAGE_DIR=/app/storage`, `DB_URL=sqlite:////app/storage/vdstream.db`, `DOWNLOAD_DIR=/app/downloads`). `VOLUME ["/app/storage", "/app/downloads"]` 선언. |
| **포트 노출** | `EXPOSE 5000` |
| **`DEFAULT_PREFIX` 환경변수** | `ENV DEFAULT_PREFIX=/vdstream` 설정. 헬스체크 `5000{prefix}` 포맷과 일치하도록 기본값 구성 및 코드에서 슬래시 유무와 무관하게 안전한 정규화 지원. |
| **헬스체크 엔드포인트** | 헬스체크 CMD: `python -c "import os, requests; prefix = os.getenv('DEFAULT_PREFIX', ''); requests.get(f'http://localhost:5000{prefix}/api/status')"`에 대응하기 위해 `/{base_prefix}/api/status` 엔드포인트 구현 및 `requests` 패키지 의존성 포함. |
| **진입점 모듈 `main:app`** | 컨테이너 루트에서 `main:app`으로 바로 로드될 수 있도록 루트 경로에 `main.py` 진입점 파일 구성 (`from app.main import app`). Uvicorn 기반 CMD 설정 및 Gunicorn 실행 가이드 제공. |
