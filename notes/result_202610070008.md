# VDSTREAM 산출물 보고서 (result_202610070008.md)

- **작성일시**: 2026-10-07 00:08 (KST)
- **작업명**: Windows 환경 FFmpeg subprocess `cp949` 디코딩 결함 (`UnicodeDecodeError`) 긴급 수정 및 인코딩 방어
- **버전**: v1.0.4

---

## 1. 결함 개요 및 문제 현상

비디오 파일 업로드 후 백그라운드 트랜스코딩 수행 시, Windows 한국어 로케일 환경에서 `subprocess.py` 내부의 `_readerthread` 스레드로부터 다음과 같은 예외가 발생하였습니다:

```text
Exception in thread Thread-12 (_readerthread):
Traceback (most recent call last):
  File "C:\...\threading.py", line 1041, in _bootstrap_inner
    self.run()
  File "C:\...\threading.py", line 992, in run
    self._target(*self._args, **self._kwargs)
  File "C:\...\subprocess.py", line 1612, in _readerthread
    buffer.append(fh.read())
UnicodeDecodeError: 'cp949' codec can't decode byte 0xa9 in position 1682: illegal multibyte sequence
```

---

## 2. 근본 원인 (Root Cause)

1. Python의 `subprocess.run(..., text=True)` 호출 시 `encoding` 파라미터를 지정하지 않으면 호스트 운영체제의 기본 ANSI 코드페이지(`locale.getpreferredencoding()`, 한국어 윈도우의 경우 `cp949`)로 stdout/stderr 파이프 스트림을 디코딩합니다.
2. FFmpeg 및 x264 라이브러리가 출력하는 콘솔 로그 및 비디오 메타데이터에는 저작권 문자(`©`, 0xA9)나 UTF-8 다국어 바이트가 포함됩니다.
3. `cp949` 코덱은 단독 바이트 `0xA9`를 유효한 멀티바이트 시퀀스로 인식하지 못하여 `_readerthread` 스레드 내에서 `UnicodeDecodeError`가 발생하고 스레드가 크래시되었습니다.

## 3. 수정 내역 및 조치

### 3.1 [`app/services/ffmpeg_service.py`](file:///C:/Dev/python/vdstream/app/services/ffmpeg_service.py) 인코딩 표준화
- `probe_video`의 `ffprobe` 실행 시:
  ```python
  result = subprocess.run(
      cmd,
      stdout=subprocess.PIPE,
      stderr=subprocess.PIPE,
      text=True,
      encoding="utf-8",
      errors="replace",
      check=True
  )
  ```
- `transcode_to_720p_and_hls`의 MP4 변환 실행 시:
  ```python
  res_mp4 = subprocess.run(
      mp4_cmd,
      stdout=subprocess.PIPE,
      stderr=subprocess.PIPE,
      text=True,
      encoding="utf-8",
      errors="replace"
  )
  ```
- `transcode_to_720p_and_hls`의 HLS 세그먼트 생성 실행 시:
  ```python
  res_hls = subprocess.run(
      hls_cmd,
      stdout=subprocess.PIPE,
      stderr=subprocess.PIPE,
      text=True,
      encoding="utf-8",
      errors="replace"
  )
  ```
- `errors="replace"` 설정을 통해 비표준 바이트가 유입되더라도 예외를 발생시키지 않고 안전하게 대체 문자(`\ufffd`)로 처리하도록 방어 체계를 확립했습니다.

### 3.2 신규 단위 테스트 추가 ([`tests/test_ffmpeg_encoding.py`](file:///C:/Dev/python/vdstream/tests/test_ffmpeg_encoding.py))
- `test_subprocess_encoding_safety_with_special_bytes`: 0xA9를 포함한 특수 바이트 디코딩 안정성 검증.
- `test_probe_video_handles_utf8_and_special_characters`: UTF-8 및 특수 문자가 포함된 메타데이터를 `ffmpeg_service`가 안전하게 처리하고 `encoding="utf-8"`, `errors="replace"`가 전달되는지 검증.
