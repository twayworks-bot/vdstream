# 사용자 원본 요구사항 및 구현 계획서 (req_202610070030.md)

- **접수일시**: 2026-10-07 00:30 (KST)
- **요청 분류**: 트랜스코딩 완료 상태 모니터링 누락 결함 해결 및 0~100% 진행률(Progress) API/대시보드 실시간 표출

---

## 1. 사용자 원본 요구사항

```text
업로드 후 transcoding 완료 상태가 모니터링되지 않아 진행중 표시가 계속 뜨는 상태로 유지되는데 이 부분이 완료상태까지
진행되고 이 때  프로그레스 상태값을 출력할 수 있도록 수정해 주세요. API로 진행상태값을  100%까지 추정할 수 있도록 
수정 가능여부를 확인 후 구현 검토 해주세요.
```

## 2. 현상 분석 및 원인 규명 (Root Cause Analysis)

### 2.1 대시보드에서 '진행중 표시가 계속 뜨는 상태로 유지'되는 원인
1. **조건부 폴링 중단 결함 (`dashboard.js`)**:
   - `startStatusPolling()` 함수는 시스템 요약 정보(`GET /api/v1/system/status`)의 `active_transcoding_count > 0 || queued_count > 0`일 때만 비디오 목록을 확인(`checkAndRefreshPendingVideos()`)하도록 설계되어 있다.
   - 워커가 트랜스코딩을 완료하여 카운터가 `0`으로 떨어지는 즉시 폴링이 중단되므로, 대시보드 화면 테이블에 남아있는 비디오 행은 이전의 `변환 중...` 상태 그대로 영구 정지된다.
   - 또한 기존 검사는 `location.reload()`를 호출하도록 되어 있어 화면 깜빡임이 심하고, 새로고침 시점이 엇갈리면 갱신되지 못한다.
2. **모델 및 API의 진행률(`progress_percent`) 미지원**:
   - `Video` 모델과 `to_dict()` 및 REST API 응답에 진행률(0~100%)을 나타내는 필드가 전혀 존재하지 않았다.
   - 클라이언트나 외부 앱에서 트랜스코딩이 몇 %까지 진행되었는지 파악할 수 있는 수단이 없었다.

## 3. 해결 및 구현 설계 (Design & Implementation Plan)

### 3.1 진행률 추적 서비스 (`ProgressTracker`) 및 비디오 모델 확장
1. **`Video` 모델 필드 추가**:
   - `progress_percent`: `Column(Float, default=0.0, nullable=False)`
   - `to_dict()`에 `progress_percent` (0.0 ~ 100.0) 포함.
   - 상태별 기본값:
     - `QUEUED`: `0.0`
     - `PROCESSING`: 실시간 계산값 (1.0 ~ 99.0)
     - `COMPLETED`: `100.0`
     - `FAILED`: `0.0`
2. **트랜스코딩 진행률 추적기 (`progress_tracker`)**:
   - 인메모리 싱글톤으로 각 `video_id`의 현재 단계, 시작 시각, 총 재생시간(`duration`), FFmpeg 진행 시간(`out_time_ms`), 현재 진행률(%)을 초 단위로 관리.
   - FFmpeg 실행 시 `-progress pipe:1`을 통해 실제 인코딩된 시간(`out_time_us`)을 실시간 파싱하여 정확한 진행률(%)을 산출.
   - MP4 인코딩 구간: 0% ~ 85%
   - HLS 세그먼테이션 구간: 85% ~ 99%
   - 완료 시: 100%
   - 만약 FFmpeg 출력 파싱이 지연되더라도 경과 시간 대비 추정치(Fallback Estimator)를 결합하여 단조 증가(monotonic increase)하는 0~99% 진행률을 보장.

### 3.2 API 확장 및 응답 스펙 동기화
- `GET /api/v1/videos/{video_id}/status`:
  - `data.progress_percent`: `45.5` (0~100 실시간 진행률)
  - `data.status`: `PROCESSING`
  - `data.status_message`: "Transcoding 720p H.264 (45%)..."
- `GET /api/v1/videos`:
  - 목록의 각 아이템에도 `progress_percent` 포함.

### 3.3 대시보드 UI 및 실시간 비동기 업데이트 개선 (`dashboard.js` & `index.html`)
1. **대시보드 테이블 UI 개선**:
   - '진행 상태' 열에 진행률 프로그레스 바(`div.progress`, `div.progress-bar`) 및 진행률 수치(예: `45%`) 렌더링.
2. **스마트 무중단 폴링 (`smartLiveTableUpdate`)**:
   - 테이블에 `QUEUED` 또는 `PROCESSING` 상태인 비디오가 하나라도 존재하면 1초 주기로 `GET /api/v1/videos?limit=20`를 호출.
   - 전체 페이지 새로고침(`location.reload()`) 없이 해당 행의 진행 상태 배지, 프로그레스 바 너비 및 텍스트를 DOM에서 즉시 실시간 갱신.
   - `COMPLETED`가 되는 순간 녹색 [완료] 배지와 [재생] 및 [링크] 버튼으로 부드럽게 UI 교체.
